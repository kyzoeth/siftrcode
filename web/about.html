About SiftrCode

Building the outcome-aware context optimization layer for autonomous coding agents.

Why SiftrCode Exists

AI coding agents like Claude Code, Cursor, and Windsurf are fundamentally bottlenecked by context windows. Dumping entire repositories into a model burns hundreds of thousands of tokens per prompt, costs dollars per turn, and causes models to hallucinate or miss the exact line they need to modify.

Naive file truncation or embedding-based vector search fails in software engineering because code is deeply relational. An agent fixing an authentication bug needs to see the full body of the authentication controller, but only needs the type signatures of the session manager, user model, and database client.

SiftrCode solves this by creating outcome-aware context bundles. Using AST parsers across TypeScript, Python, Go, and Rust, SiftrCode excises internal implementation bodies from supporting dependencies while protecting edit targets at full fidelity.

Engineering Principles

1. Outcome-Awareness

Every token spent must directly increase the likelihood of agent task success. Irrelevant deadweight is aggressively suppressed.

2. Local-First & Zero Egress

Code parsing, symbol graphs, and budgeting run 100% locally on your machine. No raw source code or secrets ever leave your environment.

3. Mathematical Rigor

Token budgets are solved using constrained linear programming, guaranteeing 100% deterministic decision plan invariance.

4. Empirically Verified

Certified against live production benchmarks (Express, FastAPI, SiftrCode) with audited lineage and zero foreign-key orphans.
